STITCH CONTROL — стартовый PWA-проект

Что работает в этой версии:
- Главная панель с суммами, активными заказами и срочными сроками.
- Создание и редактирование заказов.
- Клиент, телефон, источник, тип заказа, позиции, размер, стежки, срок, статус, цена, предоплата, примечания.
- Представление заказов: карточки, таблица, канбан.
- Расчёт остатка к оплате.
- Разделы клиенты, финансы и задачи.
- Установка как PWA и базовый офлайн-кэш.

ВАЖНО:
Данные этой первой версии сохраняются локально в браузере на конкретном устройстве (localStorage).
Облачная синхронизация между iPhone и компьютером, вход по аккаунту, push-уведомления и полноценный склад ещё НЕ подключены.
Для этого нужен сервер/облачная база данных и размещение сайта по HTTPS. Не вводите реальные клиентские данные в демонстрационную версию, пока не настроено резервное копирование и облачное хранение.

Как проверить:
1. Разместить содержимое папки на HTTPS-хостинге.
2. Открыть сайт в Safari на iPhone.
3. Нажать «Поделиться» → «На экран Домой».
4. Открыть приложение с новой иконки.

Для локального теста нужен локальный веб-сервер; запуск index.html напрямую не обеспечивает PWA-установку.
